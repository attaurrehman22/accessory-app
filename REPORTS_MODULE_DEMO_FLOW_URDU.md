## 📋 Flow 1: User - Report Submission from Chat
### (یوزر - چاٹ سے رپورٹ جمع کرانا)

### Step 1.1: Opening Chat
**English**: "First, let me open a chat conversation"
**Urdu Transliteration**: "Pehle main ek chat conversation kholta hoon"

**Action**: 
- Navigate to chat section
- Open any existing chat

**What to say**:
- "Yahan main ek chat conversation dikha raha hoon"

### Step 1.2: Opening Report Modal
**English**: "Now I will click on the report button"

**What to say**:

- "Yahan user ko report ki details fill karni hoti hain"

---

### Step 1.3: Selecting Report Type
**English**: "I need to select the type of report"
**Urdu Transliteration**: "Mujhe report ki type select karni hai"

**Action**:
- Click on "Report Type" dropdown
- Show different options:
  - Product Issue
  - Payment Issue
  - Fraud
  - Harassment
  - Other

**What to say**:
- "Pehle report ki type select karni hai"
- "Yahan 5 options hain: Product Issue, Payment Issue, Fraud, Harassment, aur Other"
- "Main Product Issue select karta hoon kyunke product mein problem hai"

---

### Step 1.4: Filling Description
**English**: "Now I will write a detailed description"
**Urdu Transliteration**: "Ab main detailed description likhunga"

**Action**:
- Type description in textarea
- Show minimum 10 characters requirement

**What to say**:
- "Ab description field mein problem ki details likhni hain"
- "Minimum 10 characters required hain"

### Step 1.5: Adding Attachments
**English**: "I can attach files like screenshots or documents"

**Action**:

### Step 1.6: Submitting Report
**English**: "Now I will submit the report"

**Action**:

- Show success message

**What to say**:

## 📝 Key Points to Remember During Demo

1. **Speak clearly and slowly**
2. **Show each step visually**
3. **Explain what you're doing**
4. **Highlight important features**
5. **Answer questions if asked**
6. **Use both English and Urdu transliteration**
